# Science Readers

The home page of Science Readers: https://sciencereaders.github.io

Science Readers builds visual learning tools for learners with no tutor to show them why a rule is true, designed for shared, low-data phones. It is organised in wings, one per subject. The Mathematics wing is **[Math Reader](https://sciencereaders.github.io/math/)**, which holds three titles: **[Geometry Reader](https://sciencereaders.github.io/geometryreader/)** ([public showcase](https://github.com/sciencereaders/geometryreader)), the first module, and the demos of **[Number Reader](https://sciencereaders.github.io/math/number/)** and **[Algebra Reader](https://sciencereaders.github.io/math/algebra/)**, both in development.

The home page and the Math Reader page are static pages with no scripts, no trackers and self-hosted fonts. `math/number/` and `math/algebra/` hold the minified public builds of the two demos (no source code); their source is private.
